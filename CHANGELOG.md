# GiftBridge changelog

## 0.3.0 — Personalized gifting and merchant studio

- New searchable, filterable gift catalog with refined responsive styling.
- Occasion and personal message customization, sender name and five selectable digital gift designs.
- Gift presentation preview, customer gift reveal, and unread/read notification inbox.
- One-time 8-digit redemption PIN generated by the gift owner; expires in 5 minutes, single use, limited invalid attempts.
- Atomic conditional card balance deduction to protect against over-redemption in demo transactions; still requires production database testing.
- Merchant reporting, local CSV export, branch management and cashier-scoped merchant access.
- Receipt popup after simulated cashier redemption.
- Windows `run.bat` bootstraps the demo environment, `launcher.py` waits for readiness and opens the local browser.
- Maintains v0.2 SQLite data by adding tables rather than modifying existing core schemas.
- Extended API and UI integration tests.
- No real gateway, voucher issuer, physical card integration or regulatory approval.

## 0.2.0 — End-to-end gift and simulated payments

- Demo purchases, failed-payment retry, once-only issuance, gifting, cashier redemptions, admin controls, ledger and settlement preview.
